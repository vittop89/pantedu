# Changelog Luglio 2026

Tutte le entry datate `2026-07-*`. Per index globale + altri mesi vedi

## 2026-07-07 — Operazioni — configurazione auto-rigenerante al boot e accesso SSH Zero Trust

Causale: dopo un riavvio del VPS l'istanza poteva partire senza `.env` o senza
le cartelle di storage; l'accesso amministrativo passava da una porta esposta.

- Guardia al boot che rigenera `.env` e le cartelle di storage se mancano
  (`fa90134`; unit `tools/systemd/pantedu-ensure-config.*`).
- Accesso SSH solo via tunnel Zero Trust, documentato per operatore e DPO
  (`277840b`, `1dbfcf0`, `f22d24e`; `docs/ops/ssh-cloudflare-tunnel.md`,
  `docs/INSTALL.md` §7).

## 2026-07-18 — Pagine di fiducia e pubblicazione — markdown reso meglio, release a un comando

Causale: le pagine `/legal/*` e `/privacy/*` rendono markdown con un parser
interno che ignorava liste e tabelle nei blockquote; la pubblicazione richiedeva
otto comandi a mano.

- `TrustPagesController`: blockquote su più righe uniti in un paragrafo,
  liste e tabelle rese anche dentro i blockquote, righe di prosa consecutive
  unite (`339af3a`, `867794b`, `a7c8931`).
- `tools/publish/release.sh`: pubblicazione a un comando con gate anti-PII
  (`cb6c253`); fine riga LF forzata sugli script di pubblicazione (`3fb0748`).
